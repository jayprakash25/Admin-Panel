# Venovet's Admin Panel

## Description

Admin panel for managing the Venovet website. This panel provides administrative functions and content management capabilities.

## Features

- User management
- Content editing
- Role-based access control
- Real-time data updates via Firebase

## Getting Started

### Prerequisites

- Node.js >= 16
- npm or yarn

### Installation

```bash
npm install
npm start
```

## Technologies Used

- React
- Firebase
- Tailwind CSS
