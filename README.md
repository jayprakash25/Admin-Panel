# Venovet's Admin Panel

## Description
Admin panel for managing the Venovet website. This panel provides administrative functions and content management capabilities.

## Features
- User management
- Content editing
- Blog management
- Company, truck, and product management
- Enquiries, careers, and newsletter management
- Category and service section editing

## Technologies Used
- React 18
- Firebase 10 (Firestore + Auth)
- Tailwind CSS + Material Tailwind
- React Router v6
- React Quill (rich text editor)

## Getting Started

```bash
npm install
npm start
```
